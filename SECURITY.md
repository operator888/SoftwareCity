# Security

Software City runs entirely in the browser and reads only the files you choose.
If you find a way for opened code, a crafted file or a pattern-library entry
to run script, read other files, or send data anywhere, please report it
privately to **theodoros@ecommercewebservices.de** instead of opening a
public issue. Expect a reply within a few days. Credit is given in the
changelog unless you ask otherwise.
